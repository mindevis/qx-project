# QX Cosmetics (Fabric)

> **Not used by QXSystem.** This mod was an experimental client-side cosmetics layer (skins, capes, wings). QXLauncher no longer installs or depends on it. QX cosmetics are **skins only** via vanilla launch — see [docs/cosmetics.md](../../docs/cosmetics.md).

Archived source for reference.

## Build

Requires JDK 21+ and Gradle wrapper:

```bash
./gradlew build
```

Output: `build/libs/qx-cosmetics-fabric.jar`
